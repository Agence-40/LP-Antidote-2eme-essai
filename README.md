# Antidote · Landing page

Landing page de l'agence **Antidote** : Google Ads & landing pages pour les entreprises du BTP.

## Contenu
- `index.html` : page autonome (HTML + CSS + JS dans un seul fichier, aucune dépendance à installer).

## Voir la page en local
Ouvrez simplement `index.html` dans un navigateur.

## Mise en ligne gratuite avec GitHub Pages
1. Dans le dépôt : **Settings → Pages**.
2. *Source* : `Deploy from a branch`, branche `main`, dossier `/ (root)`.
3. La page sera publiée sur `https://<votre-compte>.github.io/<nom-du-depot>/`.

## À compléter avant la mise en ligne
- Études de cas et témoignages (section Résultats, textes entre crochets).
- `[Votre agence]` dans le tableau comparatif et le pied de page → « Antidote ».
- Photo et présentation du fondateur, montants `[XXX] €`, nombre de places `[X]`.
- Mentions légales : adresse, SIRET, téléphone.
- Formulaire : renseigner l'URL `action` (Formspree, Make, Brevo, CRM…) pour recevoir les demandes.
